Notification Platform / защита проекта

Готовый показ: откройте POST /api/demo/scenarios/{name} → Try it out → выберите сценарий → Execute.

В ответе: статус, история событий, команды, таймеры и отправки провайдерам. Время управляется через POST /api/demo/advance.

Локальное демо: данные в памяти, провайдеры имитируются. Метрики · OpenAPI JSON · Swagger работает без интернета.
